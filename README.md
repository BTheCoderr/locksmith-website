# Locksmith Service Website

<!-- repo-intro:start -->
**Project snapshot:** A modern Next.js local-service website for presenting locksmith services, trust signals, emergency contact paths, and mobile-first conversion.

**What it demonstrates:** Next.js · React · TypeScript · Tailwind CSS · local-service conversion UX.
<!-- repo-intro:end -->

## Project purpose

This repository is a custom locksmith business website built on the Next.js App Router. The focus is clear service discovery, fast contact access, and a professional mobile experience.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
